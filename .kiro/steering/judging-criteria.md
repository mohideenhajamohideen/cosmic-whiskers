# Reddit Community Games 2025 Hackathon - Judging Criteria

This document outlines the judging criteria for the Reddit Community Games 2025 Hackathon. All development should align with these criteria to maximize scoring potential.

## Competition Categories

### 1. Best Game - Community Play ($15,000)
**Focus:** Massively multiplayer game mechanics that bring redditors together

### 2. Best Kiro Developer Experience ($10,000)
**Focus:** Creative integration of Kiro capabilities to improve development workflow

## Judging Criteria Breakdown

---

## 1. Delightful UX (Weight: High)

### What Judges Look For:
- **Exciting layouts and themes** - Visual appeal and variety
- **Easy to discover features** - Intuitive navigation and clear UI
- **Fun to explore** - Engaging gameplay and progression
- **Smooth interactions** - Responsive controls and animations

### Implementation Checklist:
- [ ] Multiple themes with distinct visuals
- [ ] Smooth 60 FPS gameplay
- [ ] Particle effects and animations
- [ ] Clear visual feedback for actions
- [ ] Intuitive controls (tap, click, keyboard)
- [ ] Progressive difficulty
- [ ] Satisfying sound effects
- [ ] Beautiful aesthetic design

### Scoring Tips:
- Add "juice" - screen shake, particles, celebrations
- Make every interaction feel responsive
- Use emojis and visual elements effectively
- Ensure mobile and desktop both feel great

**Target Score: 9-10/10**

---

## 2. Polish (Weight: High)

### What Judges Look For:
- **Close to publishable quality** - Production-ready code
- **Compliant with Devvit Rules** - Follows platform guidelines
- **Custom first screen REQUIRED** - Splash screen is mandatory
- **Self-explanatory** - Clear from demo post interaction

### Implementation Checklist:
- [ ] Custom splash screen implemented
- [ ] No console errors or warnings
- [ ] Smooth performance on all devices
- [ ] Professional appearance
- [ ] Clear instructions visible
- [ ] Error handling for edge cases
- [ ] Responsive design (mobile + desktop)
- [ ] Well-tested functionality

### Critical Requirements:
- **MUST HAVE:** Custom splash screen (not default)
- **MUST HAVE:** No bugs or crashes
- **MUST HAVE:** Professional polish

### Scoring Tips:
- Test on multiple devices
- Fix all console errors
- Add loading states
- Handle network failures gracefully
- Make splash screen impressive

**Target Score: 10/10**

---

## 3. Reddit-y (Weight: Medium-High)

### What Judges Look For:
- **Community-minded** - Built for Reddit communities
- **Own identity** - Unique and memorable
- **Fresh to platform** - Novel approach
- **Brings community together** - Social features

### Implementation Checklist:
- [ ] Reddit usernames prominently displayed
- [ ] Community leaderboards visible
- [ ] Social sharing features
- [ ] Reddit-themed elements
- [ ] Subreddit-specific features
- [ ] Community engagement hooks
- [ ] Reddit-native feel

### Scoring Tips:
- Show Reddit usernames everywhere (u/username)
- Make it feel like a Reddit game, not just a game on Reddit
- Add Reddit-specific features (karma, awards, etc.)
- Encourage community interaction
- Use Reddit's visual language

**Target Score: 8-9/10**

---

## 4. Community Play (Weight: CRITICAL for Best Game)

### What Judges Look For:
- **Central use of community play** - Not just an add-on
- **Encourages collaboration, competition, or shared goals**
- **Exciting multiplayer experiences**
- **Both synchronous and asynchronous options**

### Implementation Checklist:
- [ ] **REQUIRED:** Visible leaderboard with real-time rankings
- [ ] **REQUIRED:** Community milestones/goals
- [ ] **REQUIRED:** Player interaction visible
- [ ] Community stats prominently displayed
- [ ] Shared progress tracking
- [ ] Competitive elements (rankings, scores)
- [ ] Collaborative elements (community goals)
- [ ] Async multiplayer (ghost races, challenges)

### Critical Requirements:
- **MUST HAVE:** Leaderboard always visible on game over
- **MUST HAVE:** Community milestone tracking
- **MUST HAVE:** Visible player interaction

### Scoring Tips:
- Make community features FRONT AND CENTER
- Show other players' progress
- Create shared goals
- Add daily/weekly challenges
- Display community achievements
- Make players feel part of something bigger

**Target Score: 8-9/10** (This is the PRIMARY criterion for Best Game)

---

## 5. Best Kiro Developer Experience (Weight: CRITICAL for Kiro Award)

### What Judges Look For:
- **Creative solutions** - Novel approaches to development
- **Workflow improvements** - Measurable efficiency gains
- **Reusable approaches** - Others can use your methods
- **"Why didn't I think of that?"** - Clever innovations

### Implementation Checklist:
- [ ] **REQUIRED:** .kiro directory in repository root
- [ ] **REQUIRED:** .kiro NOT in .gitignore
- [ ] **REQUIRED:** Specs, hooks, and steering in .kiro
- [ ] **REQUIRED:** Detailed writeup OR video (under 3 min)
- [ ] **REQUIRED:** Public repository with OSI license
- [ ] Documented workflow improvements
- [ ] Measurable time savings
- [ ] Reusable patterns demonstrated
- [ ] Clear before/after comparison

### Critical Requirements:
- **MUST HAVE:** Complete .kiro folder structure
- **MUST HAVE:** Spec-driven development documented
- **MUST HAVE:** Video or writeup showing workflow
- **MUST HAVE:** Public repo with open source license

### Scoring Tips:
- Document your workflow clearly
- Show concrete time savings (hours, days)
- Demonstrate reusability
- Create video showing Kiro in action
- Highlight innovative uses of Kiro features
- Show how others can adopt your approach

**Target Score: 10/10**

## Common Pitfalls to Avoid

### ❌ Don't:
- Hide community features behind buttons
- Make single-player game without multiplayer
- Skip custom splash screen
- Forget to show Reddit usernames
- Leave .kiro folder incomplete
- Make video too long (>3 min)
- Use proprietary license
- Add .kiro to .gitignore

### ✅ Do:
- Make community features prominent
- Show leaderboard automatically
- Create impressive splash screen
- Display Reddit usernames everywhere
- Complete .kiro folder structure
- Keep video under 3 minutes
- Use OSI-approved license
- Commit .kiro folder to repo

## Notes for AI Development

When implementing features, always consider:

1. **Does this improve Community Play score?**
   - Make community features visible
   - Add player interaction
   - Show shared progress

2. **Does this improve Polish score?**
   - Fix bugs immediately
   - Add error handling
   - Test on multiple devices

3. **Does this improve Reddit-y score?**
   - Show Reddit usernames
   - Add Reddit-specific features
   - Make it feel native

4. **Does this improve Kiro score?**
   - Document workflow improvements
   - Show time savings
   - Make patterns reusable

Always prioritize features that improve multiple criteria simultaneously.
