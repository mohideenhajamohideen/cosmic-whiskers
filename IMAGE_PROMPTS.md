# 🎨 Image Generation Prompts for Cosmic Whiskers

Use these prompts in ChatGPT (DALL-E) to generate banner and icon images for your game.

---

## 🖼️ Banner Image (1920x384px)

### Prompt for ChatGPT/DALL-E:

```
Create a wide horizontal banner image (1920x384px) for "Cosmic Whiskers" - a space-themed mobile game.

Style: Vibrant, playful, cosmic aesthetic with a purple-pink nebula background

Main Elements:
- A cute orange tabby cat astronaut wearing a transparent space helmet and blue jetpack, positioned on the left side
- The cat should have a happy, adventurous expression with big eyes
- Floating in deep space with a purple and pink nebula background
- Scattered glowing stars and sparkles throughout
- 2-3 small satellites floating in the background (satellite dish, solar panel satellite, space station)
- Cosmic rings or hoops visible in the distance
- A small planet (pink or orange) in the background
- Gradient from deep purple to pink across the nebula

Text: "COSMIC WHISKERS" in bold, playful font on the right side with a glow effect

Color Palette:
- Deep purple (#6B21A8)
- Hot pink (#EC4899)
- Orange (#FB923C) for the cat
- Blue (#60A5FA) for the jetpack
- Gold (#FCD34D) for stars and accents

Mood: Fun, adventurous, cute, space exploration, casual gaming

Art Style: Modern digital illustration, slightly cartoonish but polished, suitable for a mobile game
```

## 🎯 Icon Image (512x512px)

```

Style: Simple, bold, instantly recognizable icon suitable for mobile app stores

Main Elements:
- Close-up of a cute orange tabby cat's face with a transparent space helmet

- Transparent bubble helmet with a subtle shine/reflection
- Deep space background with purple-pink nebula
- A few small stars or sparkles around the edges
- Simple and clean composition that works at small sizes

Color Palette:
- Orange (#FB923C) for the cat
- Light blue (#93C5FD) for the helmet
- Deep purple to pink gradient background (#6B21A8 to #EC4899)
- White/gold sparkles

Requirements:
- Must be clear and recognizable at small sizes (64x64px)
- Bold, simple shapes
- High contrast
- No text
- Rounded corners friendly
- Professional game icon quality

Mood: Cute, friendly, space adventure, approachable

Art Style: Clean vector-style illustration, bold outlines, suitable for app icon
```

## 📐 Image Specifications

### Banner Requirements:
- **Dimensions:** 1920x384px (5:1 ratio)
- **Format:** PNG with transparency OR JPG
- **File Size:** Under 500KB
- **Usage:** Reddit subreddit banner, GitHub repo banner

### Icon Requirements:
- **Dimensions:** 512x512px (1:1 ratio)
- **Format:** PNG with transparency
- **File Size:** Under 200KB
- **Usage:** Reddit app icon, GitHub social preview

## 🎯 Tips for Best Results

1. **Generate Multiple Variations:**
   - Try the prompt 3-4 times
   - Pick the best one or combine elements

2. **Adjust if Needed:**
   - Ask ChatGPT to "make the cat cuter"
   - Request "more vibrant colors"
   - Say "simplify for better icon clarity"

3. **Refinement Prompts:**
   - "Make the background more purple"
   - "Add more sparkles and stars"
   - "Make the cat's expression happier"
   - "Increase contrast for better visibility"

4. **Export Settings:**
   - Use PNG for transparency
   - Maximum quality
   - RGB color mode

## 📝 After Generation

### Save As:
- Banner: `banner.png` or `cosmic-whiskers-banner.png`
- Icon: `icon.png` or `cosmic-whiskers-icon.png`

### Add to Repository:
```bash
# Copy images to assets folder
cp ~/Downloads/banner.png cosmic-whiskers/assets/
cp ~/Downloads/icon.png cosmic-whiskers/assets/

# Commit
git add assets/
git commit -m "Add banner and icon images"
git push
```

### Use in Reddit:
1. **Subreddit Banner:**
   - Go to your subreddit settings
   - Upload banner.png
   - Adjust positioning

2. **App Icon:**
   - Update `devvit.json` to reference the icon
   - Or upload directly in Reddit Developer Portal
